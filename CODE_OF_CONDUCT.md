# Code of conduct

Tessera adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its code of conduct. It applies to everyone taking part in the project: in issues, pull requests, discussions, reviews and any other project space, and when representing the project elsewhere.

In short: be respectful, assume good faith, critique work rather than people, and do not harass anyone. The Covenant defines the expected and unacceptable behavior in full.

## Reporting

Report conduct issues privately to the maintainer at **lyk-boya@outlook.com**. Please include links or screenshots where possible. Reports are handled confidentially, and the reporter's identity is not shared without consent.

The maintainer responds following the Covenant's enforcement guidelines. A maintainer involved in a report does not take part in handling it.
